# Aliber Print — versões

Instaladores do **Aliber Print**, o servidor de impressão da Aliber Informática / Sistemas.

- **Instalação nova:** baixe o `AliberPrint-Instalador.exe` da [versão mais recente](https://github.com/marketingaliber/aliber-print-versoes/releases/latest).
- **Atualização:** no Aliber Print, *Configurações > Escolher versão* (área do técnico). Para quem está numa versão anterior à 1.3.2, rode uma vez o `AliberPrint-Atualizacao-X.Y.Z.exe`.

Suporte: Aliber Informática / Sistemas.
